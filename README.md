# 2048

Jogo 2048 em HTML/CSS/JS puro, publicado com GitHub Pages e otimizado para celular.

**Jogar:** https://joaopsf1.github.io/teste/

- Deslize o dedo (ou use as setas / WASD) para mover as peças.
- Botão ↶ desfaz a última jogada.
- O recorde e a partida atual ficam salvos no navegador.
- Pode ser instalado na tela inicial e funciona offline.
