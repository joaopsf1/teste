# Alan Gay

Jogo em pixel art: o Alan, sempre de roupa azul e sorrindo, precisa escapar dos zumbis petistas que invadiram o Edifício Sede III. Feito em HTML/CSS/JS puro, publicado no GitHub Pages e otimizado para celular.

**Jogar:** https://joaopsf1.github.io/teste/

- Arraste o dedo em qualquer lugar da tela para andar (joystick virtual). No computador: setas ou WASD; `P`/`Esc` pausa.
- A cada 20 segundos o Alan sobe um andar e aparecem mais zumbis.
- Pegue os cafés ☕ para ganhar pontos e velocidade por alguns segundos.
- 3 vidas; o recorde fica salvo no navegador.
- Pode ser instalado na tela inicial e funciona offline.
